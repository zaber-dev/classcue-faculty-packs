# ClassCue faculty lists

Ready-made faculty lists for [ClassCue](https://classcue.zealtyro.com), the class routine app for university students. Each file is one university's teachers with their designation, department, e-mail, phone and photo where the university publishes them: **32,969 teachers at 69 universities**.

## Use a list

1. Download the university's `.cqfaculty` file (links below, or from the [website](https://classcue.zealtyro.com/universities/)).
2. In ClassCue open the **Faculty** tab, tap **+**, then **Import from a file**, and pick the file.

ClassCue shows what it found and asks before adding anything. Teachers already in your list only get their missing details filled in; nothing you wrote is overwritten.

## Layout

```
<country>/<SHORT> - <University name>.cqfaculty
```

The file names are the ones the website links to, so a list can be fetched from `https://raw.githubusercontent.com/zaber-dev/classcue-faculty-packs/main/<country>/<file>`.

## Where the data comes from

Every list is compiled from the faculty pages each university publishes on its own website. Nothing is invented: a field the page does not show for a person is left empty, office-wide phone numbers and e-mail addresses shared by many people are left out, and pages that are not people are skipped.

If you are listed and want your entry corrected or removed, write to support@zealtyro.com.
